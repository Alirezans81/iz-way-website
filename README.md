# ایزی وِی (IZ Way) — وب‌سایت انتقال ارز

وب‌سایت فارسی، راست‌چین و ریسپانسیو برای انتقال ارز بین ایران و سایر کشورها (و بالعکس).

## امکانات

- **صفحه لندینگ** — معرفی خدمات و مراحل کار
- **فرم ثبت درخواست انتقال ارز** — کشور/ارز/مبلغ/پلتفرم مبدأ، مقصد، تحویل نقدی (مشهد) و راه ارتباطی
- **ثبت‌نام و ورود با ایمیل** (نام، نام خانوادگی، شماره موبایل با کد کشور — بدون تأیید)
- **صفحه پروفایل** — مشاهده اطلاعات کاربر و درخواست‌های ثبت‌شده

## پشته فنی

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** — تم رنگ شرابی، فونت وزیرمتن، راست‌چین
- **Prisma + SQLite** برای دیتابیس (به‌راحتی قابل تغییر به PostgreSQL)
- احراز هویت با **JWT در کوکی httpOnly** + **bcrypt**

## راه‌اندازی

```bash
npm install
npx prisma db push      # ساخت دیتابیس
npm run dev             # اجرا روی http://localhost:3000
```

## ساختار پروژه

```
src/
  app/
    page.tsx              صفحه لندینگ
    request/page.tsx      فرم ثبت درخواست
    login/ register/      صفحات احراز هویت
    profile/page.tsx      پروفایل کاربر
    api/
      auth/               register | login | logout | me
      requests/           ثبت و فهرست درخواست‌ها
  components/             Header, Footer, Logo, LogoutButton
  lib/
    prisma.ts             کلاینت دیتابیس
    auth.ts               نشست، رمزنگاری
    constants.ts          ارزها، کدهای کشور، راه‌های ارتباطی
prisma/schema.prisma      مدل‌های User و TransferRequest
```

## توسعه‌های بعدی (پیشنهاد)

- پنل مدیریت برای مشاهده و تغییر وضعیت درخواست‌ها
- تأیید ایمیل/شماره موبایل
- مهاجرت دیتابیس به PostgreSQL (تغییر `provider` در `schema.prisma`)
- اعلان به کارشناس هنگام ثبت درخواست (تلگرام/ایمیل)

## نکات امنیتی

پیش از انتشار در محیط واقعی، مقدار `AUTH_SECRET` در فایل `.env` را به یک رشته تصادفی و امن تغییر دهید.
